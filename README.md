# Sales Prediction  

This project aims to build a machine learning model for predicting sales using the dataset `Train.csv`. The notebook includes data preprocessing, exploratory data analysis (EDA), feature engineering, and model training with multiple regression algorithms such as Linear Regression, Lasso, Ridge, Decision Tree Regressor, Random Forest Regressor, Extra Trees Regressor, XGBRegressor, LGBMRegressor, and CatBoostRegressor. Models are evaluated using R² score and error metrics, with hyperparameter tuning performed through RandomizedSearchCV and cross-validation. The implementation uses Python libraries including numpy, pandas, matplotlib, seaborn, scikit-learn, xgboost, lightgbm, and catboost. Results highlight the best-performing model, providing insights for accurate sales forecasting.
